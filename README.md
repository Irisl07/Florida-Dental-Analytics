# Florida Advanced GP Career Analytics & Decision Support System

## Overview
This project evaluates Florida dental markets for advanced implant-focused general dentists.

The objective is to identify locations that maximize:
- Income potential
- Implant opportunity
- Career growth
- Practice environment quality

## Tools
- Python
- Pandas
- Matplotlib
- CSV Data Modeling

## Key Findings
Top Markets:
1. Naples
2. Sarasota
3. Port St. Lucie
4. Boca Raton
5. Fort Myers

## Project Components
- Market Analysis
- Opportunity Scoring Model
- Scenario Analysis
- UF Student Strategy
- Business Recommendations
