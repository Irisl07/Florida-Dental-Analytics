# Florida Dental Location Analytics Data Schema

## Market Information

| Field | Description |
|---------|---------|
| City | Florida city |
| Region | Geographic region |
| Population | Total population |
| PopulationGrowth | Population growth rate |

## Income Potential

| Field | Description |
|---------|---------|
| AdvancedGPIncomePotential | Estimated income potential for a high-performing GP |
| ImplantPotential | Potential demand for implant treatment |

## Patient Demand

| Field | Description |
|---------|---------|
| MedianHouseholdIncome | Median household income |
| SeniorPopulationPercent | Population age 65+ |
| AffluentPatientScore | Estimated concentration of affluent patients |

## Competition

| Field | Description |
|---------|---------|
| DentistDensity | Dentists per population |
| CompetitionScore | Overall competition level |

## Living Cost

| Field | Description |
|---------|---------|
| SafeArea2BRRent | Average 2-bedroom rent in safe areas |
| CostOfLivingIndex | Cost of living index |

## Final Score

| Field | Description |
|---------|---------|
| DentalOpportunityScore | Overall career opportunity score |
## Practice Environment

| Field | Description |
|---------|---------|
| ProcedureFreedomScore | Ability to perform advanced procedures |
| ImplantOpportunityScore | Potential implant case volume |
| TechnologyScore | Availability of advanced technology |
| ProductionOpportunityScore | Ability to produce high-value treatment |
| SupportInfrastructureScore | Strength of support systems |
